# APEX Compute visualizer

This is the interactive presentation layer for the APEX Compute project. It follows
the local `tel/Layers/threejs_implementation_plan.md.md` notes and turns the three
mechanisms into navigable views:

- **Overview** — home page with a live 3D matrix scene, command preview, benchmark facts, and entry points.
- **Execution flow** — cache tiling, playback controls, tile timeline, and engine vs. naive explanation.
- **SIMD kernels** — scalar, NEON 4×4, and AVX-512 register-lane view with an instruction trace.
- **Thread pool** — disjoint output ownership and worker queue visualization.

## Run it

```sh
npm install
npm run dev
```

Open the Vite URL printed in the terminal (normally `http://localhost:5173`).

The browser can preview the local command and animate the execution path, but it
does not spawn Python processes. Use **Import run** to load a JSON file generated by
`apex-bench.py --json-out ...`; imported runner metrics replace the sample values in
the visualizer.
